# Titanic-Survival-Prediction
**Titanic Survival Prediction** — A machine learning project that analyzes passenger data to predict survival outcomes. Built using Python, Pandas, NumPy, Scikit-learn, and TensorFlow, with data preprocessing, model training, and evaluation.
Titanic Survival Prediction 🚢

A machine learning project that predicts whether a passenger survived the Titanic disaster based on passenger information such as age, gender, passenger class, fare, and family details.

📌 Project Overview

The goal of this project is to build a machine learning model that can identify patterns in passenger data and predict survival outcomes.

The project covers the complete machine learning workflow, including data loading, preprocessing, model development, training, and evaluation.

🎯 Objectives
Explore and understand the Titanic passenger dataset.
Clean and prepare the data for machine learning.
Select relevant features for prediction.
Train a machine learning model to predict survival.
Evaluate the model's performance.
📊 Dataset

The project uses the Titanic dataset, which contains information about passengers and their survival status.

Key features include:

Passenger Class
Sex
Age
Number of Siblings/Spouses
Number of Parents/Children
Fare
Embarked Port
Survival Status

The dataset is loaded directly from a public GitHub dataset source within the notebook.

🛠️ Technologies Used
Python
Pandas – Data manipulation and analysis
NumPy – Numerical operations
Scikit-learn – Data preprocessing and model utilities
TensorFlow / Keras – Machine learning model development
Matplotlib – Data visualization
Jupyter Notebook – Development environment
